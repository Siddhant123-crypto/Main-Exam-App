A full‑stack Exam Application System built using React, Node.js (Express), and DBMS (MySQL). This project allows administrators to manage exams and questions, while students can securely log in and take exams online.The Exam Application System is designed to simplify the process of exam creation, management, and evaluation. It provides role‑based access for Admin and Student, ensuring secure and efficient examination workflows. Tech Stack: Frontend React.js. HTML5, CSS3. Axios (API communication).

Backend Node.js. Express.js. JWT Authentication.

Database MySQL (DBMS). Tools. Git & GitHub. Postman (API Testing).

Features Admin Module. Admin Login & Authentication. Create / Update / Delete Exams. Add & Manage Questions. Assign Questions to Exams. View Student Results.

Student Module Student Registration & Login. View Available Exams. Attempt Exams.
